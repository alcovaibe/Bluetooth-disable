# Bluetooth Disable

**Язык:** [Русский](README.md) | [English](README_EN.md)

Bluetooth Disable — Android-приложение для системной блокировки Bluetooth через Android Device Policy.

В режиме защиты приложение работает как Device Policy Controller (DPC) и, будучи назначенным Device Owner, применяет системное ограничение `UserManager.DISALLOW_BLUETOOTH`. Пока ограничение активно, Android запрещает штатное включение и использование Bluetooth. Дополнительно приложение пытается немедленно выключить уже активный адаптер.

> **Статус проекта:** основная функциональность и четыре Cover Mode реализованы. Проект находится на стадии release hardening и финального тестирования.

## Возможности

- системная блокировка Bluetooth через Device Owner;
- немедленная попытка выключить активный Bluetooth при включении защиты;
- сохранение системного ограничения после закрытия приложения и перезагрузки устройства;
- состояния `OFF / PROTECTED`;
- Quick Settings tile;
- смена launcher-значка и названия приложения;
- четыре полноценных режима маскировки:
  - Калькулятор;
  - Заметки;
  - Календарь;
  - Галерея;
- отдельный скрытый способ входа из каждого Cover Mode;
- аварийное восстановление через системную аутентификацию Android;
- русский и английский интерфейс;
- светлая и тёмная темы;
- работа без root, Shizuku, Magisk и Accessibility Service;
- отсутствие фонового сетевого сервиса;
- отсутствие аналитики и телеметрии;
- отсутствие разрешения `INTERNET`.

## Cover Mode

Cover Mode меняют launcher-идентичность приложения и стартовый интерфейс. Это не просто смена иконки: каждый режим содержит отдельный рабочий локальный интерфейс.

### Калькулятор

После настройки пользователь задаёт пятизначный код доступа. Основной интерфейс Bluetooth Disable открывается после ввода кода и нажатия `=`.

Код не хранится в открытом виде: используется HMAC-SHA256 и неэкспортируемый ключ Android Keystore.

Если код забыт, откройте историю калькулятора и удерживайте заголовок **«История» 3 секунды**, затем пройдите системную аутентификацию и подтвердите сброс маскировки.

[Актуальная документация Calculator Cover Mode](docs/covermode/calculator/ru/README.md)

### Заметки

Notes Cover Mode предоставляет локальные текстовые заметки, чек-листы, форматирование, изображения и избранное.

При настройке выбирается заметка и секретный фрагмент текста. Нажатие по этому фрагменту в выбранной заметке открывает Bluetooth Disable. Правило доступа проверяется через HMAC-SHA256 с ключом Android Keystore.

Аварийное восстановление запускается удержанием кнопки `+` **3 секунды** и требует системной аутентификации.

[Подробная документация Notes Cover Mode](docs/covermode/notes/ru/NOTES_COVER_MODE.md)

### Календарь

Calendar Cover Mode предоставляет локальный календарь с заметками по датам.

При настройке выбираются секретная дата и текст. Для входа в Bluetooth Disable необходимо создать на этой дате заметку с настроенным текстом и открыть её. Начальные и конечные пробелы не учитываются, регистр и остальной текст учитываются.

Аварийное восстановление запускается удержанием заголовка календаря или элемента перехода к сегодняшней дате **3 секунды**.

[Подробная документация Calendar Cover Mode](docs/covermode/calendar/ru/CALENDAR_COVER_MODE.md)

### Галерея

Gallery Cover Mode — локальная приватная галерея. Фотографии импортируются через Android Photo Picker и копируются во внутреннее хранилище приложения.

Для скрытого доступа выбирается секретная фотография и последовательность из трёх разных зон экрана. Секрет проверяется через HMAC-SHA256. Файлы и служебные данные галереи защищаются локальным шифрованием с ключами Android Keystore.

Аварийное восстановление запускается удержанием заголовка **«Галерея» 3 секунды**.

[Подробная документация Gallery Cover Mode](docs/covermode/gallery/ru/GALLERY_COVER_MODE.md)

## Аварийное восстановление

Recovery flow использует системную аутентификацию Android:

- биометрию;
- PIN-код устройства;
- графический ключ;
- пароль устройства.

После успешной проверки пользователь отдельно подтверждает сброс активной маскировки. Отмена аутентификации или подтверждения не меняет текущий Cover Mode.

Если Quick Settings tile уже добавлен, Bluetooth Disable также можно открыть через плитку.

## Как работает защита Bluetooth

Основной механизм:

```text
Device Owner
    ↓
DevicePolicyManager
    ↓
UserManager.DISALLOW_BLUETOOTH
    ↓
Android запрещает использование Bluetooth
```

После применения ограничения приложение повторно проверяет фактическое состояние policy. Прямая команда выключения Bluetooth используется только как best-effort ускорение видимого отключения адаптера.

## Конфиденциальность

Bluetooth Disable придерживается принципа минимальных разрешений.

Приложение:

- не содержит рекламы;
- не содержит аналитики или трекеров;
- не имеет разрешения `INTERNET`;
- не сканирует Bluetooth-устройства;
- не получает местоположение;
- не перечисляет сопряжённые устройства;
- не подключается к удалённым Bluetooth-устройствам;
- не отправляет заметки, фотографии или другие пользовательские данные на сервер.

На Android 12+ разрешение `BLUETOOTH_CONNECT` используется только для best-effort немедленного выключения локального Bluetooth-адаптера. Device Owner может предоставить его приложению через Device Policy.

## Хранение и перенос данных

Пользовательские данные приложения исключены из Android backup и device-to-device transfer как на старых, так и на новых версиях Android.

Дополнительно `DeviceTransferGuard` использует случайный marker и неэкспортируемый HMAC-ключ Android Keystore. Если OEM-инструмент всё же скопирует app-private файлы на другое устройство без исходного Keystore-ключа, локальное состояние сбрасывается к состоянию чистой установки.

## Требования

- Android 8.0 (API 26) или новее;
- для системной блокировки Bluetooth приложение должно быть назначено Device Owner.

Обычное назначение Device Owner выполняется во время первоначальной настройки Android и обычно требует factory reset устройства.

## Установка через Device Owner QR

Стабильный QR последней опубликованной сборки:

![Device Owner QR](docs/bluetooth-disable-device-owner-qr.png)

Базовый сценарий установки:

1. сохраните нужные данные и выполните factory reset устройства;
2. на первом экране Android Setup Wizard откройте режим QR provisioning — на многих устройствах для этого требуется несколько раз нажать на свободную область первого экрана;
3. подключитесь к Wi-Fi, когда Setup Wizard попросит это сделать;
4. отсканируйте QR выше;
5. дождитесь загрузки и проверки APK;
6. завершите provisioning и обычную первоначальную настройку Android;
7. после запуска Bluetooth Disable проверьте статус Device Owner и работу защиты.

Конкретное поведение Setup Wizard может отличаться у производителей Android-устройств.

[Документация Device Owner QR provisioning](docs/QR_PROVISIONING.md)

## Релизы

Все новые релизы используют единый формат тегов:

```text
v<version>
```

Например `v1.0.20`.

Release APK имеет имя:

```text
BluetoothDisable-v<version>.apk
```

При публикации `v*` workflow автоматически:

1. собирает и подписывает release APK;
2. создаёт GitHub Release;
3. вычисляет SHA-256 опубликованного APK;
4. создаёт Device Owner provisioning JSON и QR;
5. прикладывает QR/JSON к Release;
6. обновляет стабильный QR и provisioning JSON в `docs/` ветки `main`.

## Сборка и тестирование

Проект использует Kotlin, Jetpack Compose, Material 3, Android Device Policy и Android Keystore.

PR CI выполняет:

- unit tests;
- Android Lint;
- debug build;
- instrumentation test APK build;
- minified signed test release build;
- instrumentation-тесты на Android API 26–36.

После merge `Android Full Compatibility` повторно проверяет `main` на API 26–36.

Для production release используется отдельный signing keystore через GitHub Actions secrets или локальный `keystore.properties`.
