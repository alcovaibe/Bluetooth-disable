# Bluetooth Disable

**Язык:** [Русский](README.md) | [English](README_EN.md)

Bluetooth Disable — приложение для Android, которое позволяет системно заблокировать Bluetooth на устройстве.

В отличие от обычного выключения Bluetooth, режим защиты использует возможности Android Device Policy. Пока защита активна, Android запрещает штатное включение и использование Bluetooth.

## Возможности

- системная блокировка Bluetooth;
- мгновенное отключение Bluetooth при включении защиты;
- сохранение защиты после закрытия приложения и перезагрузки устройства;
- простой ручной режим `OFF / PROTECTED`;
- быстрый доступ через плитку быстрых настроек Android;
- возможность скрыть приложение из списка приложений;
- русский и английский интерфейс;
- работа без root;
- работа без Shizuku, Magisk и Accessibility Service;
- отсутствие фонового сервиса;
- отсутствие аналитики и телеметрии;
- отсутствие доступа в Интернет.

## Как работает защита

Bluetooth Disable работает как **Device Policy Controller (DPC)** и получает статус **Device Owner**.

При включении защиты приложение применяет системное ограничение Android:

`UserManager.DISALLOW_BLUETOOTH`

После этого сама операционная система запрещает использование Bluetooth до снятия ограничения.

Состояние защиты хранится на уровне Android Device Policy и не зависит от того, запущено приложение или нет.

## Конфиденциальность

Bluetooth Disable разработан с принципом минимальных разрешений.

Приложение:

- не содержит рекламы;
- не содержит аналитики;
- не содержит трекеров;
- не имеет разрешения `INTERNET`;
- не сканирует Bluetooth-устройства;
- не получает местоположение;
- не перечисляет сопряжённые устройства;
- не подключается к Bluetooth-устройствам.

На Android 12 и новее разрешение `BLUETOOTH_CONNECT` используется для немедленного выключения локального Bluetooth-адаптера при активации защиты.

## Требования

- Android 8.0 или новее;
- устройство должно быть настроено с Bluetooth Disable в качестве Device Owner.

Назначение Device Owner для обычного пользовательского устройства требует первоначальной настройки после сброса устройства.

Bluetooth Disable находится в активной разработке.

Основной механизм системной блокировки Bluetooth уже реализован и протестирован на реальном Android-устройстве.

Поддержка и поведение могут отличаться в зависимости от производителя устройства и версии Android.
