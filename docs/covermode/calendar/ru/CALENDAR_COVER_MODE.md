# Calendar Cover Mode

## Назначение

Режим «Календарь» маскирует Bluetooth Disable под локальный календарь с заметками по датам. После активации launcher открывает Calendar Cover Mode, а основной интерфейс Bluetooth Disable доступен через заранее настроенную комбинацию даты и текста заметки либо через аварийное восстановление.

## Возможности

Текущая реализация поддерживает:

- календарь по месяцам;
- переход между месяцами;
- выбор даты;
- быстрое возвращение к сегодняшней дате;
- создание, редактирование и удаление заметок для конкретной даты;
- локальное хранение заметок;
- светлую и тёмную темы.

## Настройка скрытого доступа

1. Пользователь выбирает режим «Календарь» и подтверждает переход.
2. В setup-экране выбирается секретная дата.
3. Задаётся секретный текст длиной от 3 до 100 символов.
4. После финального подтверждения правило доступа сохраняется и режим активируется.

Секретная заметка не создаётся автоматически при настройке. Пользователь позже самостоятельно создаёт обычную календарную заметку на выбранной дате.

Для проверки доступа дата включается в подписываемые данные вместе с нормализованным текстом. Сам секрет не хранится в открытом виде как отдельное значение: сохраняется HMAC-SHA256, а ключ находится в Android Keystore.

## Открытие Bluetooth Disable

Чтобы открыть основной интерфейс:

1. перейти на настроенную дату;
2. создать заметку с настроенным текстом;
3. открыть эту заметку.

Перед проверкой удаляются пробелы только в начале и конце текста. Регистр и внутренние символы сохраняются, поэтому остальной текст должен совпадать точно.

Кнопка **«СКРЫТЬ»** возвращает пользователя в Calendar Cover Mode, переводит календарь к сегодняшней дате и очищает переход к основному интерфейсу из back stack.

## Аварийное восстановление

На основном экране календаря удерживайте заголовок календаря или элемент перехода к сегодняшней дате **3 секунды**. После этого запускается системная аутентификация Android. При успешной проверке пользователь подтверждает сброс маскировки.

Если Quick Settings tile добавлен, Bluetooth Disable также можно открыть через плитку.

Отмена системной аутентификации или подтверждения не изменяет активный режим.

## Хранение данных

Календарные заметки хранятся локально в зашифрованном виде. `CalendarNotesCipher` использует AES-GCM с ключом Android Keystore. Правило скрытого доступа использует отдельный HMAC-SHA256 ключ.

Данные приложения исключены из Android backup и device-to-device transfer. Дополнительный `DeviceTransferGuard` обнаруживает перенесённое app-private состояние по отсутствию неэкспортируемого Keystore-ключа и возвращает локальное состояние к чистой установке.

## Основные компоненты

- `CalendarCoverActivity` — контейнер режима и recovery flow;
- `CalendarCoverSetupActivity` — настройка даты и секретного текста;
- `CalendarViewModel` — состояние календаря и заметок;
- `LocalCalendarNotesRepository` — локальное хранилище;
- `CalendarNotesCipher` — шифрование заметок;
- `CalendarAccessManager` — HMAC-проверка даты и текста;
- `CalendarAccessPolicy` — нормализация и ограничения секрета;
- `CalendarDraftStore` — сохранение незавершённого ввода заметки.

## Проверки

Calendar Cover Mode покрыт unit- и instrumentation-тестами, включая:

- правила текста доступа;
- работу с датами;
- CRUD и шифрование заметок;
- сохранение черновика после recreation;
- setup и переход в активный режим;
- навигацию cover/main;
- recovery и отмену аутентификации;
- 3-секундный recovery-жест;
- устойчивость тестов к медленным старым API.

Instrumentation-тесты запускаются общей CI-матрицей Android API 26–36.
