# Notes Cover Mode

## Назначение

Режим «Заметки» маскирует Bluetooth Disable под локальное приложение для заметок. После активации launcher открывает Notes Cover Mode, а основной интерфейс Bluetooth Disable доступен только через заранее настроенный скрытый фрагмент заметки или механизм аварийного восстановления.

## Возможности

Текущая реализация поддерживает:

- обычные текстовые заметки;
- чек-листы;
- создание, редактирование и удаление заметок;
- избранное;
- форматирование текста;
- добавление изображений;
- локальную генерацию тестовых заметок;
- локальное хранение без сетевой синхронизации;
- светлую и тёмную темы.

## Настройка скрытого доступа

1. Пользователь выбирает режим «Заметки» и подтверждает переход.
2. В setup-экране можно создать новую заметку, отредактировать существующую или сгенерировать локальные заметки.
3. Выбирается одна заметка, которая будет использоваться для доступа к Bluetooth Disable.
4. В тексте выбранной заметки выделяется секретный фрагмент длиной до 80 символов.
5. После подтверждения режим активируется и открывается Notes Cover Mode.

Для правила доступа сохраняются идентификатор заметки и границы выбранного фрагмента. Сам секрет не хранится отдельной строкой: для проверки используется HMAC-SHA256 с неэкспортируемым ключом Android Keystore.

## Открытие основного интерфейса

Пользователь открывает настроенную заметку и нажимает внутри секретного фрагмента. Доступ разрешается только если одновременно выполняются условия:

- открыта именно настроенная заметка;
- нажатие попало внутрь сохранённого диапазона;
- текущий текст в этом диапазоне совпадает с тем, который был настроен;
- HMAC успешно проверяется ключом Android Keystore.

Если секретная заметка редактируется или удаляется, интерфейс показывает дополнительное предупреждение. Это снижает риск случайно уничтожить настроенный способ доступа.

## Аварийное восстановление

На основном экране Notes Cover Mode удерживайте кнопку `+` **3 секунды**. После этого запускается системная аутентификация Android. При успешной проверке пользователь подтверждает сброс маскировки.

Если Quick Settings tile уже добавлен, приложение также можно открыть через плитку.

Отмена аутентификации или отказ от подтверждения не изменяют активный режим.

## Хранение данных

Заметки сохраняются только локально. Репозиторий заметок использует AES-256-GCM, а ключ шифрования хранится в Android Keystore. Ключ шифрования данных отделён от HMAC-ключа скрытого доступа.

Данные исключены из Android backup и device-to-device transfer. Дополнительно `DeviceTransferGuard` проверяет локальную идентичность установки по отдельному неэкспортируемому Keystore-ключу и сбрасывает перенесённое состояние при обнаружении копирования на другое устройство.

## Основные компоненты

- `NotesCoverActivity` — контейнер режима и recovery flow;
- `NotesCoverSetupActivity` — выбор заметки и секретного диапазона;
- `NotesViewModel` — UI-состояние и операции с заметками;
- `LocalNotesRepository` — локальное хранилище;
- `NotesCipher` — AES-256-GCM для данных заметок;
- `NotesAccessManager` — HMAC-проверка скрытого фрагмента;
- `NotesPolicy` — ограничения и валидация;
- `NotesGenerator` — локальная генерация заметок.

## Проверки

Для режима есть unit- и instrumentation-тесты, включая:

- генерацию заметок;
- сохранение и чтение локального репозитория;
- persistence после перезапуска;
- навигацию между Notes Cover Mode и Bluetooth Disable;
- жест удержания recovery;
- сохранение поведения скрытого доступа.

Instrumentation-тесты запускаются общей CI-матрицей Android API 26–36.
