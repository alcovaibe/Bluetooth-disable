# Calculator Cover Mode

## Назначение

Режим «Калькулятор» заменяет launcher-идентичность Bluetooth Disable и открывает рабочий интерфейс калькулятора вместо основного экрана приложения. Режим предназначен для маскировки интерфейса без изменения системной функции Bluetooth Disable.

## Настройка и вход

1. Пользователь выбирает значок «Калькулятор».
2. После подтверждения задаётся пятизначный код доступа.
3. После успешной активации приложение перезапускается с launcher-идентичностью калькулятора.
4. Для открытия основного интерфейса необходимо ввести сохранённый пятизначный код и нажать `=`.
5. Кнопка «СКРЫТЬ» в основном интерфейсе возвращает пользователя в активный Calculator Cover Mode.

Код состоит только из ASCII-цифр `0–9`. Сам код в открытом виде не хранится. Для проверки используется HMAC-SHA256, а ключ создаётся в Android Keystore и не экспортируется из устройства.

## Калькулятор

Текущая реализация поддерживает:

- сложение, вычитание, умножение и деление;
- скобки и стандартный порядок операций;
- отрицательные и десятичные числа;
- проценты;
- обработку деления на ноль и некорректных выражений;
- историю до 50 последних вычислений;
- локализованный десятичный разделитель;
- светлую и тёмную темы.

Вычисления выполняются собственным parser/evaluator на базе `BigDecimal`.

## Аварийное восстановление

Если код забыт, доступны два пути восстановления:

- открыть приложение через Quick Settings tile, если плитка добавлена;
- открыть историю калькулятора и удерживать заголовок «История» **3 секунды**.

После удержания запускается системная аутентификация Android. При успешной проверке пользователь подтверждает сброс маскировки. Отмена или неуспешная аутентификация не меняет активный режим.

## Хранение и перенос

Код доступа и история хранятся только локально. Данные приложения исключены из Android backup и device-to-device transfer. Дополнительно `DeviceTransferGuard` использует отдельный неэкспортируемый Keystore-ключ и при обнаружении перенесённого состояния возвращает приложение к состоянию чистой установки.

## Основные компоненты

- `CalculatorCoverActivity` — контейнер режима и recovery flow;
- `CalculatorViewModel` — состояние калькулятора;
- `CalculatorEngine`, `CalculatorTokenizer`, `CalculatorParser`, `CalculatorEvaluator` — вычислительный слой;
- `CalculatorAccessCodeManager` — защищённая проверка кода;
- `CalculatorHistoryStore` — локальная история;
- `CalculatorHistoryDrawer` — история и recovery target.

## Проверки

Режим покрыт unit- и instrumentation-тестами, включая:

- политику пятизначного кода;
- математический движок;
- хранение и проверку verifier;
- навигацию между cover и основным интерфейсом;
- recovery и отмену системной аутентификации;
- жест удержания recovery.

Instrumentation-тесты запускаются общей CI-матрицей Android API 26–36.
